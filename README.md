# README - Projet TP4 : Recettage

## Présentation du Projet
Ce projet consiste à développer et valider une application en suivant un cahier des charges précis. Le processus comprend la rédaction d'un cahier de recettage, le développement collaboratif de l'application, et la validation des fonctionnalités via des tests.

## Lien vers le Repository
Le projet complet est disponible sur GitHub : [Repository complet](https://github.com/agpinedam/TP4-Validation.git)

## Cahier de Recettage
Un cahier de recettage a été créé à partir du cahier des charges fourni. Il a été mis à jour au fur et à mesure des tests pour inclure les résultats et ajouter des cas d'usage éventuellement oubliés.
- **Lien vers le cahier de recettage :** [Cahier Recette](https://docs.google.com/spreadsheets/d/1eijfpuLieX2If7ieEhhTGWYCI-mtZyM3fQORRz1wnsY/edit?usp=sharing)  
- Un export PDF de ce cahier est également inclus dans le repository.

## Processus Suivi
1. Rédaction initiale du cahier de recettage.
2. Développement collaboratif du projet.
3. Mise à jour du cahier de recettage avec les résultats des tests.
